## How to capture them

- Use a real device or emulator running the actual app (native Android build, not the web preview).
- Full-screen screenshots (Power + Volume Down on Android), status bar included is fine.
- Any modern Android phone resolution works (e.g. 1080×2400, 1080×2340, 1440×3200) — the
  compositor crops to a ~9:19.5 window, so avoid extreme aspect ratios.
- PNG or JPG, no cropping/edits needed — send them straight off the device.
- Use populated/realistic data (a doctor with a photo, a real-looking consultation) rather
  than empty states, so the screenshots aren't misleading.
